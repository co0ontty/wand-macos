1. 首页草稿的归属任务列表只在首次初始化时获取。另一个目录入口创建任务后，侧栏已更新，
   返回首页草稿的菜单仍缺少新任务。现在页面重现、归属浮层打开和任务列表变更都会刷新选项，
   合并并发请求；刷新失败保留旧列表并可重试。输入、目录、模型和显式选择不重新初始化。
   最终安装版实测：保存验收任务的新名称后返回已有首页草稿，菜单显示新名称，原多行草稿仍保留。
2. 非 Git 目录被显示为绿色“工作区干净”。现在显式区分非 Git、加载、错误、状态缺失、
   干净与有改动；重命名/冲突/其他文件状态也计入变更。错误不提供快捷提交，刷新期间禁用旧提交入口。
   最终安装版在真实非 Git 工作目录显示中性“此目录未启用 Git”，没有快捷提交按钮。
3. 独立代码复查补齐弹层快速关闭时的取消边界：读取由草稿持有，发起弹层销毁不会取消共享读取，
   并发任务变更不会丢失。顶部标题改为直接观察草稿，与正文和任务按钮共用当前任务名解析。
   这两项补充由取消场景和标题回归测试验证，锁屏后尚未完成新构建的真机复验。
