## 真机发现并修复

1. 显示/隐藏连接信息时，SecureField / TextField 替换会自动全选，继续输入可能覆盖原值。
   现在在切换前保存 UTF-16 选区，在新 field editor 获得焦点后恢复。
   最终安装版验证末尾追加保留原文，以及跨切换保留局部选区、继续编辑仅替换该选区。
2. 命令面板选择设置后，关闭时 AppKit 仍可能将原 sheet 视为 key window，快捷键保护误丢弃命令。
   现在先保存选择，再在关闭后的主队列发送该显式操作；普通 sheet 的快捷键保护保持。
   最终安装版中筛选“设置”并 Return 已实际进入设置。
3. 连接 sheet 顶栏改为明确的68 pt，滚动区域使用同一高度扣减，避免新按钮高度造成无意义滚动。
