## 历史与尚未具备的能力

当前服务端 `registerProviderHistoryRoutes` 对六种 provider 的 `GET /api/<provider>-history` 均返回空数组：产品已停止把工具自己的历史文件导入 Wand 列表。六种工具在 Wand 创建的会话均由 `/api/sessions` 提供和恢复，不能把旧 UI/旧扫描器残留当作当前支持的历史导入能力。

macOS 为旧服务器保留 Claude/Codex 历史兼容读取。某一个兼容端点失败时保留该来源的旧快照，不让已经成功的 Wand 会话刷新失败；成功的空响应会清掉对应旧记录。未知来源不会落入 Claude 的删除/恢复接口。

Web 的语音按钮当前没有语音识别后端，代码明确显示「网页端暂不支持语音输入」。工具窗口不把它描述为可用语音识别，macOS 也未新增录音/识别实现。

## 内嵌工具契约

- 一个工具窗口共用一个 WKWebView，切换分组不重载页面，不重新登录，不丢失底层选中会话和已打开的文件。
- 使用 Web 已公开的业务控制器定位页面；文件面板通过 `__wandDesktopTools.openFiles()` 幂等打开，认证后的 Shell 尚未挂载时不执行。
- 导航只关闭其管理的设置/Issue 浮层；文件编辑器和预览的内容、保存冲突、放弃修改提示仍由 Web 控制器持有。并行任务不可关闭时停止切换并解释原因。
- 关闭工具窗口前读取文件编辑状态：保存中保留窗口，存在草稿则提供继续编辑/放弃修改确认。此检查通过当前版本服务器的只读 `getCloseState()` 桥接完成，旧服务器缺少该桥时沿用旧客户端关闭行为。
- 脚本异常或未知的关闭状态不会被当作「无草稿」；窗口保留并提供重试，强制关闭须明确确认放弃修改。切换服务器菜单不能穿透工具弹窗。
- 不绕过设置管理员登录或服务端权限。WK 原生消息仅接受所连接服务器的顶层同源页面；外部网页交系统浏览器打开。
- 页面完成导航不等同于 React/认证已就绪。工具定位等待就绪，超时后保留页面，提供重试和完整控制台入口；旧服务器缺少文件导航桥时明确说明兼容情况。
- 文件选择使用 macOS 标准面板；用户取消选择会返回取消结果。证书上传沿用服务端表单与权限校验。
